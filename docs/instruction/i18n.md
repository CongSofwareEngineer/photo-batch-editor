# Đa ngôn ngữ (English / Tiếng Việt)

- **Mục đích:** giao diện tiếng Anh và tiếng Việt.
- **File:** `rust/core/src/i18n.rs`, `rust/core/src/i18n_vi.rs`, `rust/core/src/i18n_vi_data.json`,
  `rust/gui/src/app.rs`, `rust/gui/src/login.rs`
- **Changelog:** [../changelog/i18n.md](../changelog/i18n.md)
- **Ghi chú:** mã Python (`core/i18n.py`, `core/i18n_vi.py`) đã xoá; bản dịch nằm trong `i18n_vi_data.json` (nhúng qua `i18n_vi.rs`).

## Logic chính

- Chữ tiếng Anh là key: `tr("…")`; bản dịch tiếng Việt nằm trong `rust/core/src/i18n_vi_data.json`
  (nhúng qua `i18n_vi.rs`).
- Chọn ngôn ngữ ở Settings › General hoặc màn đăng nhập → dựng lại cửa sổ ngay, giữ thư mục,
  chỉnh sửa và setting.
- Lần đầu mở app: theo ngôn ngữ hiển thị của Windows.

## Lưu ý / giới hạn

- Mọi chữ hiển thị mới phải dùng `tr("…")` và thêm bản dịch vào `i18n_vi_data.json` (trước đây là
  `core/i18n_vi.py`, nay đã xoá).

## Test

- `rust/core/src/i18n.rs` / `i18n_vi.rs` có `#[cfg(test)]` kiểm tra key ↔ bản dịch (bản port của
  `tests/test_i18n.py` cũ). Thêm `tr("…")` mới mà thiếu bản tiếng Việt thì test fail.
