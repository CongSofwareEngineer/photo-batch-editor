# Changelog: Port sang Rust

> Hiện trạng logic: [../instruction/rust-port.md](../instruction/rust-port.md)

- 2026-10-09 | Thêm mới | Port sang Rust: lập kế hoạch port theo giai đoạn, cài Rust toolchain (rustup, stable 1.99), tạo Cargo workspace `rust/` với crate `pbe-core` — vì chuyển cả app desktop PyQt6 sang Rust là việc nhiều giai đoạn, cần làm từng bước build + test được.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ1 — core logic thuần): port `version`, `system`, `paths`, `settings`, `scanner`, `auth`, `i18n`, `i18n_vi`, `presets` và phần tính toán của `image_size` sang Rust; 42 `cargo test` xanh, phản chiếu các test Python (`test_version/scanner/auth/presets/image_size/i18n`). i18n tiếng Việt sinh tự động từ `core/i18n_vi.py` → `rust/core/src/i18n_vi_data.json` để khớp 100% — vì port tay 590 mục dễ sai lệch placeholder.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ2 — số học ảnh): port `backend` (Gaussian/box/block-mean/bilinear khớp OpenCV), `adjustments` (15 chỉnh sửa, bản fused planar), `pipeline` (apply_adjustments) và `image_size` resample (`resize.rs`). Thêm `tools/gen_rust_fixtures.py` sinh fixture tham chiếu từ bản Python; test Rust (`tests/fixtures_numeric.rs`) chứng minh khớp trong sai số (adjustments max 3e-3; proc u8 ≤ 1 mức; identity bằng đúng ảnh vào) — vì port số học phải giữ nguyên kết quả nhìn thấy.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ3 — I/O, Super Resolution, batch): port `io_utils` (đọc PNG/JPEG/BMP/TIFF 8/16-bit, alpha composite, xoay theo EXIF; ghi JPEG q100 4:4:4 + EXIF reset Orientation + ICC) dùng `image`/`jpeg-encoder`/`kamadak-exif`; `enhance` (Super Resolution ONNX qua `ort`, sau feature `sr`, khớp Python ≤ 2/255); `batch` CPU đa luồng (thread pool, process_log, hủy). Thêm `tools/gen_io_fixtures.py` + `tests/io_roundtrip.rs`, `tests/batch_cpu.rs`, `tests/sr_onnx.rs`. `pipeline::process` nhận `Option<&dyn Upscaler>` để tách ONNX khỏi `core` — vì ONNX runtime nặng, chỉ kéo khi bật `sr`.
