# Changelog: Port sang Rust

> Hiện trạng logic: [../instruction/rust-port.md](../instruction/rust-port.md)

- 2026-10-09 | Thêm mới | Port sang Rust: lập kế hoạch port theo giai đoạn, cài Rust toolchain (rustup, stable 1.99), tạo Cargo workspace `rust/` với crate `pbe-core` — vì chuyển cả app desktop PyQt6 sang Rust là việc nhiều giai đoạn, cần làm từng bước build + test được.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ1 — core logic thuần): port `version`, `system`, `paths`, `settings`, `scanner`, `auth`, `i18n`, `i18n_vi`, `presets` và phần tính toán của `image_size` sang Rust; 42 `cargo test` xanh, phản chiếu các test Python (`test_version/scanner/auth/presets/image_size/i18n`). i18n tiếng Việt sinh tự động từ `core/i18n_vi.py` → `rust/core/src/i18n_vi_data.json` để khớp 100% — vì port tay 590 mục dễ sai lệch placeholder.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ2 — số học ảnh): port `backend` (Gaussian/box/block-mean/bilinear khớp OpenCV), `adjustments` (15 chỉnh sửa, bản fused planar), `pipeline` (apply_adjustments) và `image_size` resample (`resize.rs`). Thêm `tools/gen_rust_fixtures.py` sinh fixture tham chiếu từ bản Python; test Rust (`tests/fixtures_numeric.rs`) chứng minh khớp trong sai số (adjustments max 3e-3; proc u8 ≤ 1 mức; identity bằng đúng ảnh vào) — vì port số học phải giữ nguyên kết quả nhìn thấy.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ3 — I/O, Super Resolution, batch): port `io_utils` (đọc PNG/JPEG/BMP/TIFF 8/16-bit, alpha composite, xoay theo EXIF; ghi JPEG q100 4:4:4 + EXIF reset Orientation + ICC) dùng `image`/`jpeg-encoder`/`kamadak-exif`; `enhance` (Super Resolution ONNX qua `ort`, sau feature `sr`, khớp Python ≤ 2/255); `batch` CPU đa luồng (thread pool, process_log, hủy). Thêm `tools/gen_io_fixtures.py` + `tests/io_roundtrip.rs`, `tests/batch_cpu.rs`, `tests/sr_onnx.rs`. `pipeline::process` nhận `Option<&dyn Upscaler>` để tách ONNX khỏi `core` — vì ONNX runtime nặng, chỉ kéo khi bật `sr`.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ4 — `core/photo/` + `core/video/`): port `photo/{effects,geometry,history,collage,image_io}.rs` (kèm kiểu `photo::RgbaImage`) và `video/{ffmpeg,project,export}.rs`; thêm `backend::gaussian_blur_exact` (blur luôn ở độ phân giải gốc, khớp `cv2.GaussianBlur` — bản `gaussian_blur` cũ thu nhỏ khi sigma lớn nên không dùng được cho hiệu ứng nhìn thấy) và `adjustments::apply_adjustments_planar_u8_ls` (ghi đè `long_side` cho ảnh xem trước thu nhỏ). 29 unit test mới phản chiếu `tests/test_photo_core.py` + `tests/test_video.py`, thêm `tests/video_export.rs` xuất video thật bằng FFmpeg (4 test) — vì đây là phần cuối của `core/` trước khi làm GUI.
- 2026-10-09 | Thêm mới | Port sang Rust (GĐ5 — GUI `rust/gui/`): chọn **egui 0.36 + renderer wgpu** (`eframe`), canvas ghép bằng CPU vào framebuffer RGBA rồi tải lên texture wgpu (kiểu crate `pixels`) nên pixel trên màn hình đúng bằng pixel xuất file; port vỏ app + sidebar + state.json, đăng nhập, 3 màn hình chỉnh nhiều ảnh, bảng 15 chỉnh sửa + SR + Image Size, xem trước trước/sau chạy luồng nền, photo editor (zoom/pan kiểu Photoshop, crop theo tỉ lệ, xoay/lật, layer ảnh + layer blur, undo/redo, xuất JPEG/PNG), video editor (timeline, cắt/xoá/đổi chỗ/trim, In/Out, tắt tiếng, nhạc, xuất kèm tiến độ + huỷ), trang Settings (preset / tài khoản / ngôn ngữ). Thêm `gui/tests/cpu_render.rs` (11 test cho phần CPU) — vì GUI là phần rủi ro nhất, cần chạy được và test được phần quyết định pixel.
- 2026-10-09 | Thêm mới | Port sang Rust (thư mục dữ liệu GUI): thêm `paths::app_data_dir()` (`%APPDATA%` / `~/Library/Application Support` / `$XDG_DATA_HOME`, ghi đè bằng `PBE_APP_DATA`) — vì GUI Rust phải đọc **cùng** `auth.json` / `state.json` / `presets` với bản Python (`QStandardPaths.AppDataLocation`), không phải thư mục đệm `local_appdata_dir()`.
- 2026-10-09 | Sửa | Port sang Rust (phần còn thiếu của GĐ5): layer chữ của photo editor, vẽ chữ lên video, hộp thoại collage, file dự án `.pbep`, phát video có tiếng, trình xem ảnh toàn màn hình **chưa** port — chặn chính là rasterize chữ có dấu tiếng Việt trong Rust (cần `cosmic-text`); ghi rõ trong bảng GĐ5 của instruction để lần sau làm tiếp đúng chỗ.
- 2026-10-09 | Sửa | Port sang Rust (xoá bản Python): xoá toàn bộ mã Python (`core/`, `ui/`, `tests/`, `main.py`, `dev.py`), config/script build Python (`pyproject.toml`, `pytest.ini`, `requirements*.txt`, `PhotoBatchEditor.spec`, `lint.{bat,sh}`, `dev.{bat,sh}`, `build_mac.sh`, `build_windows.bat`, `build_installer.bat`, `installer.iss`, các tool `tools/*.py` + `build_bootloader.bat` + `sign_windows.ps1`) và artifact (`venv/`, `build/`, `dist/`, cache). Rust là codebase duy nhất; README viết lại sang bản Rust — vì đã chuyển hẳn sang Rust, giữ lại code Python chỉ gây lệch và dư thừa.
